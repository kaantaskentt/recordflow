# Security policy

Security fixes are applied to the latest commit on `main`.

Please report suspected vulnerabilities through GitHub's private vulnerability reporting flow. Do not open a public issue containing credentials, personal data, or an unpatched exploit.

RecordFlow handles workflow recordings, narration, extracted text, and AI-generated analysis. Before production use, operators must review authentication, Supabase row-level security, storage access, retention, model-provider data handling, upload limits, and PII redaction behavior.
